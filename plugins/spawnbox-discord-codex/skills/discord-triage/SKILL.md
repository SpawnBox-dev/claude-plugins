---
name: discord-triage
description: Triage a SpawnBox Discord bug or feature request using evidence, duplicate checks, scoped forum actions and durable work tracking.
---

Follow discord-help's context and authority rules. Read policy `triage` and the
current forum history, including attachments. Verify the reported behavior and
deployed version; separate observation from inference. Search existing memory
and forum evidence before declaring a duplicate. Preserve the reporter's intent.

Use orchestrator to record evidence and work. Use forum_action to merge defined
tags on the current thread; preserve unrelated tags. Archive only when the shared
workflow calls for it and the resolution is recorded. Do not expose internal
work IDs, code details or staff notes in public status updates. Reply with the
user-visible disposition and next step, or explicitly remain silent if a human
has already covered it. A forum operation receipt is the evidence of completion.
